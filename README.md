\# Image Editor



image editor with filters and YOLO object detection.



\## Features

\- Blur, Gaussian, Sharpen, Median, Bilateral

\- Flip, Rotation, Noise, Resize

\- Undo / Redo / History

\- Camera capture

\- Object Detection (YOLOv8)

\- Dark theme



\## Install

```bash

pip install -r requirements.txt

python image\_editor.py
